Cara Mendapatkan Telegram Chat ID Anda

  1. Buka aplikasi Telegram dan cari bot @userinfobot.
  2. Klik tombol Start. Bot akan membalas dengan info profil beserta deretan angka Id Anda.
  3. Salin angka Id tersebut ke kolom di atas.
  4. Penting: Pastikan Anda juga telah membuka bot Telegram server Anda (yang tokennya disetel di TELEGRAM_BOT_TOKEN) dan klik /start agar bot tersebut diizinkan mengirim pesan ke Anda.
